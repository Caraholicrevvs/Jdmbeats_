🌟 The Three AI Domains

💬 Natural Language Processing

What is NLP?

Natural Language Processing is a branch of AI that allows computers to understand, interpret, process and generate human language, including text and speech.

How does NLP work?

1. Tokenisation: Breaks sentences into smaller units such as words or tokens.

2. Syntactic Analysis: Analyses grammatical structure and relationships between words.

3. Semantic Analysis: Understands the meaning of words and sentences.

4. Pragmatic Analysis: Understands the intended meaning using context.

5. Discourse Integration: Understands relationships between sentences in a conversation.

Applications

• Chatbots
• Google Translate
• Voice assistants
• Sentiment analysis
• Spam detection
• Text summarisation

Challenges

Sarcasm, slang, ambiguity, accents, spelling mistakes and understanding context.

Fun example: "This game is sick!" may mean the game is awesome, not that it is unhealthy!

👁️ Computer Vision

What is Computer Vision?

Computer Vision is an AI domain that enables computers to analyse, understand and extract information from images and videos.

How does it work?

1. An image or video is captured.
2. The system analyses visual features.
3. AI identifies patterns and objects.
4. The system produces an interpretation.

Applications

• Facial recognition
• Self-driving cars
• Medical image analysis
• Object detection
• CCTV analysis
• Plant disease detection

Challenges

Lighting, camera angles, blurry images, objects being hidden, and similar-looking objects.

Fun example: Your phone can recognise a cat in a photograph without understanding the word "cat".

📊 Data Science

What is Data Science?

Data Science involves collecting, organising, analysing and interpreting data to discover patterns, draw conclusions and support decision-making.

Typical process

1. Collect data.
2. Clean and organise data.
3. Analyse patterns.
4. Visualise information.
5. Draw conclusions or make predictions.

Applications

• Weather forecasting
• Business analysis
• Sports statistics
• Healthcare research
• Recommendation systems
• Traffic analysis

Challenges

Missing data, inaccurate information, biased datasets, privacy concerns and incorrect interpretations.

Fun example: Analysing your favourite music genres and creating a graph showing which genre is most popular.

🧠 Can you identify the domains?

Human language, text or speech? → NLP

Images, videos or visual information? → Computer Vision

Numbers, tables, graphs and patterns? → Data Science

Real-world AI systems can use multiple domains together! For example, a self-driving car can use Computer Vision to see roads and Data Science to analyse sensor information.
